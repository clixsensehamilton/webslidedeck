## Hook
AI, machine learning, and deep learning get used interchangeably in most conversations. They're not the same thing — but they're not unrelated either. The relationship between them is the foundation of everything this series covers.

## Scene 1 — Three Terms, One Nested Structure
These three technologies aren't competing alternatives. They're nested layers. Artificial intelligence is the outermost container — the broad field of building systems that exhibit intelligent behaviour. Machine learning is a subset of AI: a specific approach where systems learn from data rather than following hand-coded rules. Deep learning is a subset of machine learning: a particular technique that uses layered neural networks to tackle problems involving perception, pattern recognition, and unstructured data.

## Scene 2 — The Matryoshka Model
Think of the relationship like a set of Russian nesting dolls. The outermost doll is AI — the widest possible frame. Open it and you find ML inside — a more specific method. Open that and you find deep learning at the core — the most specialised layer. Every deep learning system is a machine learning system. Every machine learning system is an AI system. But not every AI system uses machine learning, and not every ML system uses deep learning.

## Scene 3 — Why the Distinction Matters in Practice
When someone says "we're using AI," that tells you almost nothing about what's actually running. When they say "we're using machine learning," you know data is being used to train a model rather than rules being written by hand. When they say "deep learning," you know neural networks are involved and the problem likely involves perception — vision, speech, language, or complex sensor data. Each level of specificity changes what the system needs: data volume, compute, interpretability, and maintenance overhead all shift.

## Scene 4 — Data Science Is the Universe This All Lives In
All three — AI, ML, and deep learning — exist within the broader field of data science. Data science provides the tools, techniques, and knowledge to turn data into actionable outcomes. AI, ML, and DL are the brush strokes; data science is the canvas. This week we'll go through each layer's function, see it in production examples, and map it to infrastructure IT already manages.

## Takeaway
AI contains ML. ML contains deep learning. Knowing which one you're actually dealing with tells you what the system needs and how it can fail.

## Visual Direction
Build the nesting structure incrementally. Start with the outer ring labelled "AI" — wide, sparse. Then a second inner ring appears: "Machine Learning." Then a third innermost ring: "Deep Learning." Each ring is a distinct colour, progressively more saturated toward the centre. Labels appear as each ring builds. Hold the final three-ring diagram, then add a surrounding field labelled "Data Science" as the outermost context. Clean, concentric, no decorative elements.
